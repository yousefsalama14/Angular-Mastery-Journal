المتغيرات (Variables)

علبة بتحفظلك قيمة عشان تستخدمها تاني بدل ما تكتبها كل مرة
let name = "Youssef"; console.log(name);
Youssef

الأنواع التلاتة

في JS فيه 3 طرق تعرّف بيها متغير:

1. var — القديم، من زمان

var age = 25;

2. let — الجديد، ينفع تغيّره

let age = 25; age = 26; // تمام، اتغيرت

3. const — الجديد، لما القيمة مش هتتغير

const age = 25; age = 26;
TypeError: Assignment to constant variable.

why ليه اتعمل let/const أصلاً؟

عند var مشكلة اسمها Scope (نطاق الرؤية). المتغير بيقدر "يهرب" من مكان مفروض يكون محبوس فيه.

if (true) { var x = 10; } console.log(x);
10

x اتعرف جوه الـ if، بس طلع منها بسهولة. ده بيسبب bugs في المشاريع الكبيرة لأن متغيرات بتتسرب لأماكن مش المفروض تكون فيها.

if (true) { let y = 10; } console.log(y);
Uncaught ReferenceError: y is not defined

y اتحبس جوه أقواس الـ if ومقدرش يطلع. ده اسمه Block Scope، وده السلوك الصح.

امتى تستخدم كل واحد؟

النوعاستخدمه لما
constالقيمة مش هتتغير — الافتراضي في 90% من الحالات
letالقيمة هتتغير لاحقًا، زي counter
varمتستخدموش خالص — موجود بس عشان كود قديم
خلفية: الـ JS engine بيعمل حاجة اسمها Hoisting — بيرفع تعريفات المتغيرات لفوق الملف قبل التنفيذ. var بترفع وتتحط قيمتها undefined، أما let/const بترفع بس بتفضل في منطقة اسمها Temporal Dead Zone، يعني موجودة بس متقدرش توصلها قبل سطرها.

نقطة مهمة: const مع object

const مش معناها إن القيمة متجمدة تمامًا. لو كانت object، تقدر تغيّر محتوياته:

const person = { name: "Youssef" }; person.name = "Ahmed"; // تمام، شغالة
const person = { name: "Youssef" }; person = { name: "Ahmed" }; // استبدال كامل
TypeError: Assignment to constant variable.

const بتمنع استبدال المتغير نفسه، مش تغيير محتوياته. هنرجعلها بالتفصيل عند Objects.
