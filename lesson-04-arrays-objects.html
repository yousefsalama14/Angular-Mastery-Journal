المصفوفات والكائنات (Arrays & Objects)

إزاي تخزن مجموعة بيانات مرتبطة ببعض، مش قيمة واحدة بس
بمنطق بسيط: Array زي رف كتب — كل كتاب له مكان مرقّم (0، 1، 2...). Object زي دولاب ملفات — كل حاجة ليها اسم مكتوب عليها (label)، مش رقم.

Arrays — قوائم مرتبة بأرقام

const hobbies = ["coding", "reading", "gym"]; console.log(hobbies[0]); console.log(hobbies.length);
→coding
→3

كل عنصر في الـ Array له "رقم مكان" (index)، وبيبدأ من صفر مش من واحد. أول عنصر index بتاعه 0، مش 1.

أهم Array methods

push / pop — إضافة أو حذف من الآخر

const list = ["a", "b"]; list.push("c"); console.log(list); list.pop(); console.log(list);
→["a", "b", "c"]
→["a", "b"]

unshift / shift — إضافة أو حذف من الأول

const list = ["b", "c"]; list.unshift("a"); console.log(list);
→["a", "b", "c"]
بمنطق بسيط: push/pop بيتعاملوا مع آخر العربية القطار، unshift/shift بيتعاملوا مع أول العربية. الاتنين ممكن يضيفوا أو يشيلوا، الفرق بس فين المكان.

Objects — بيانات بمفاتيح

const user = { name: "Youssef", age: 25, city: "Shibin El Kom" }; console.log(user.name); console.log(user["city"]);
→Youssef
→Shibin El Kom

تقدر توصل للقيمة بطريقتين: dot notation (user.name) أو bracket notation (user["city"]). الطريقة التانية مفيدة لو اسم المفتاح متغير وليس ثابت.

النمط الأكتر شيوعًا: Array of Objects

ده الشكل اللي هتشوفه في كل مكان تقريبًا، خصوصًا في Angular لما تعرض قايمة بيانات (زي قايمة مستخدمين أو منتجات):

const users = [ { name: "Youssef", age: 25 }, { name: "Ahmed", age: 30 } ]; console.log(users[0].name); console.log(users[1].age);
→Youssef
→30

array بيحتوي عناصر، كل عنصر منها object بيمثل "سجل" كامل بمعلوماته. ده بالظبط شكل البيانات اللي بتيجي من أي API غالبًا.

key Higher-Order Array Methods

دول أهم 3 دوال هتستخدمها كل يوم تقريبًا في الشغل، والتلاتة بياخدوا callback function (فاكر الدرس اللي فات؟):

forEach — نفّذ حاجة لكل عنصر، من غير ما ترجع نتيجة

const nums = [1, 2, 3]; nums.forEach((n) => console.log(n * 2));
→2
→4
→6

map — حوّل كل عنصر لحاجة جديدة، وارجعلي array جديدة بالكامل

const nums = [1, 2, 3]; const doubled = nums.map((n) => n * 2); console.log(doubled);
→[2, 4, 6]

filter — رجّعلي بس العناصر اللي بتحقق شرط معين

const nums = [1, 2, 3, 4]; const evens = nums.filter((n) => n % 2 === 0); console.log(evens);
→[2, 4]
ليه ده مهم في Angular: الطريقة دي بالظبط هي اللي هتستخدمها كل يوم عشان تجهّز بيانات من الـ API قبل ما تعرضها في الصفحة — مثلاً تعمل filter على قايمة منتجات، أو map عشان تجهّز شكل البيانات المناسب للعرض.

new Destructuring — استخراج القيم بسرعة

اتضافت في ES6، وهي طريقة تختصر بيها استخراج قيم من array أو object من غير ما تكرر الاسم كل مرة:

قبلها (الطريقة القديمة):

const user = { name: "Youssef", age: 25 }; const name = user.name; const age = user.age;

بعدها (Destructuring):

const user = { name: "Youssef", age: 25 }; const { name, age } = user; console.log(name, age);
→Youssef 25

نفس الفكرة شغالة مع arrays برضو، بس بالترتيب مش بالاسم:

const colors = ["red", "green", "blue"]; const [first, second] = colors; console.log(first, second);
→red green

new Spread Operator — نشر العناصر

الرمز ... بياخد كل عناصر array أو object وينشرهم مكان تاني. مفيد جدًا لما تحب تعمل نسخة من array/object وتضيف عليها من غير ما تغيّر الأصلية:

const nums1 = [1, 2]; const nums2 = [...nums1, 3, 4]; console.log(nums2);
→[1, 2, 3, 4]
const user = { name: "Youssef" }; const updatedUser = { ...user, age: 25 }; console.log(updatedUser);
→{ name: "Youssef", age: 25 }
ليه ده مهم: فاكر درس Data Types لما اتكلمنا إن الـ objects بتشتغل بـ reference؟ الـ spread بيعملك نسخة جديدة فعليًا بدل ما تعدّل على الأصلية بالغلط. ده أسلوب أساسي في Angular وأي كود حديث عشان تتجنب الـ bugs بتاعة الـ reference.

خلاصة: امتى تستخدم إيه

الأداةاستخدمها لما
Arrayقايمة عناصر بترتيب معين، مش مهم أسماء
Objectبيانات مرتبطة بأسماء واضحة (مفاتيح)
mapعايز array جديدة بنفس العدد، بس القيم اتغيرت
filterعايز جزء بس من array حسب شرط
forEachعايز تنفذ حاجة بس، مش محتاج نتيجة جديدة
Destructuringعايز تستخرج قيم بسرعة من غير تكرار
Spreadعايز نسخة جديدة، مش تعديل على الأصلية
سؤال مقابلة 1

"إيه الفرق بين map و forEach؟" — سؤال أساسي جدًا، والإجابة الصح لازم تذكر إن map بترجع array جديدة وforEach لأ.

سؤال مقابلة 2

"إزاي تعمل نسخة من object من غير ما تأثر على الأصلي؟" — بيختبر فهمك لـ Spread Operator ومشكلة الـ Reference.

سؤال مقابلة 3

"إيه هو الـ Destructuring وليه بنستخدمه؟" — سؤال شائع في مقابلات الكود الحديث.
